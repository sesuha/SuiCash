# SuiCash execution evidence

_Generated by `pnpm evidence` in Phase 9 (handbook 9.5): real Base Sepolia transaction hashes,
each with a Basescan link._

## Phase 2 acceptance (pending testnet funding)

- Contracts deployed and verified on Base Sepolia: run `pnpm deploy:testnet`. The addresses are
  written to `contracts/deployments/84532.json`.
- A raw `executeTransfer` to an attacker reverting with `RecipientNotAllowed`: run
  `pnpm raw-attack testnet`. The hashes are written to `docs/evidence/phase2-raw-attack.json`.

The same raw-attack flow has been run on a local anvil chain: the attack transaction reverted
with `RecipientNotAllowed(0x000000000000000000000000000000000000dEaD)`, and the attacker's
balance stayed at 0. Local hashes are not evidence, so they are not recorded here.
